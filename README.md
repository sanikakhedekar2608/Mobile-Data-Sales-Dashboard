📱 Mobile Data Sales Dashboard | Power BI
📌 Project Overview
This project is an interactive Mobile Data Sales Dashboard developed using Microsoft Power BI. It provides insights into mobile sales performance, customer ratings, payment methods, brand performance and mobile model sales.
The dashboard helps analyze sales trends and understand customer purchasing behaviour through interactive visualizations.

🛠️ Tools & Technologies
- Microsoft Power BI
- Power Query
- Data Visualization
- Data Analysis
📊 Key Performance Indicators (KPIs)
- **Customer Ratings:** 465
- **Price Per Unit:** 5.24M
- **Total Units Sold:** 591
- **Total Transactions:** 127

📈 Dashboard Visualizations
1. **Transactions by Payment Method** – Analyzes transactions across Cash, Debit Card and UPI.
2. **Customer Ratings by Rating Status** – Displays Good, Average and Poor customer ratings.
3. **Units Sold by Mobile Model and Day** – Shows sales trends across different days.
4. **City-wise Analysis** – Geographical visualization of sales locations.
5. **Units Sold by Mobile Model** – Compares sales performance of different mobile models.
6. **Brand Performance Table** – Compares units sold and transaction counts across brands.

🎛️ Interactive Filters (Slicers)
- Payment Method
- Mobile Model
- Brand
- Month

🎯 Project Objectives
- Analyze mobile sales performance.
- Identify popular mobile brands and models.
- Understand customer ratings.
- Compare different payment methods.
- Track monthly sales trends.
- Explore city-wise sales distribution.
